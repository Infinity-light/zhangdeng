# 示例

两局跑完的团，各一整套导出文件。都是线上环境、真模型（智谱 Flash 免费型号）跑的，用 `node ops/make-examples.mjs` 从存档重新生成。

## 《雾港来信》—— 潮痕规则，54 轮

种子 `wugang-demo`，按 `tests/script-50.json` 连跑 54 轮（2 人类 + 1 AI 寻访者），然后回滚到第 20 轮开了一条平行分支。

| 文件 | 是什么 |
|---|---|
| `示例存档-雾港来信.json` | 完整存档（spec + 两条分支的日志与每轮快照 + 随机源状态）。首页「打开存档」导入即可续团 |
| `雾港来信.module.spec.json` | 编译并审阅过的 spec |
| `示例Replay-雾港来信-掌灯人视角.md / .html` | 掌灯人全知视角的 Replay（含每轮导演单） |
| `示例Replay-雾港来信-玩家视角.md` | 玩家视角的 Replay（陆衡的席位） |
| `示例日志-雾港来信-main.jsonl` | 主线分支的只追加日志，一行一条事件 |
| `示例状态库-雾港来信.json / .md` | 收团时的状态库 |
| `示例角色卡-雾港来信.json / .md` | 三位寻访者的角色卡 |

## 《枯井》—— 通行百分骰规则，26 轮

按 `tests/case-kujing.json` 跑 26 轮（2 人类 + 1 AI 调查员），走到「封井」；然后回滚到第 16 轮走了「下井」。文件名同上，把「雾港来信」换成「枯井」。

## 怎么用

- 想看一局完整的团长什么样：浏览器直接打开 `示例Replay-…-掌灯人视角.html`。
- 想接着跑：启动服务后在首页「打开存档」里选 `示例存档-….json`。导入时会逐条验日志的哈希链。
- 想拿数据做二次分析：`.jsonl` 日志和 `.json` 状态库是全量的；事件类型见 `docs/module.spec字段说明.md` 和 `engine/store.mjs`。
